你好，我是 **Dapeng**，一名 Java 后端开发工程师。

这里是 **DapengKernel**，我的技术笔记本。我关心一个功能如何实现，也关心它为什么这样设计：数据是否一致，异常能否定位，代码在几个月后还能不能看懂。

## 我的技术方向

主要围绕 Java 后端开发，逐步把语言基础、框架使用和系统运行串起来。比起记住一串配置，更希望弄清楚配置解决了什么问题，以及它在什么条件下不再适用。

| 方向 | 关注的内容 |
| --- | --- |
| Java 与 JVM | 集合、并发、内存模型、垃圾回收与性能分析 |
| Spring Boot | 模块划分、接口设计、事务边界与测试 |
| MySQL 与 Redis | 索引、慢查询、缓存策略和数据一致性 |
| Linux 与 Docker | 日志、进程、网络排查及应用运行环境 |
| 分布式系统 | 超时、重试、幂等、可观测性与故障处理 |

## 为什么写博客

学习时看懂一个概念，和过一段时间仍然能解释清楚，是两回事。写下来能暴露那些“好像懂了”的地方，也方便下一次遇到问题时找到思路。

我希望这里留下的不只是结论，还有问题的背景、尝试过的办法、选择的理由，以及方案的局限。短笔记也有价值，只要能把一个问题说清楚。

## 这里会记录什么

- **Java 基础与进阶**：从语言细节到 JVM 和并发机制，尽量配上小例子。
- **中间件与数据库**：整理查询、缓存和一致性问题，说明适用条件。
- **项目实践**：记录分层、接口、测试和重构中的具体选择。
- **系统设计**：讨论取舍，不把某一种架构当成标准答案。
- **运行与排障**：留下可复用的检查顺序和命令，减少重复摸索。

文章中的演示代码用于说明问题，实际应用还需要结合业务约束。遇到理解有误或过时的内容，我会在后续修订时补充说明。
